One piece at a time

A map of the work ahead.

storykōbō is being built in stages. This roadmap is intentionally broad: it shows the direction of travel, not a promise that every feature has a deadline.

Current stage: Foundation and identity. The project repository, documentation, initial Laravel application, and local development environment are established. Username validation and uniqueness are implemented and tested; the complete account and profile workflow remains to be built.

Development phases

Phase 0 — FoundationEstablished

  • ✓ Repository and project documentation
  • ✓ Working terminology and architecture principles
  • ✓ Initial Laravel application and local environment

Phase 1 — IdentityCurrent focus

  • Account registration and login/logout
  • Permanent numeric user IDs
  • Username claiming and public profile URLs
  • Basic profiles, account settings, and privacy foundations
  • Username validation and uniqueness — implemented and tested

Phase 2 — Community foundationPlanned

  • Roles, groups, and memberships
  • Basic activity model
  • Following, subscriptions, and notifications

Phase 3 — Creative workPlanned

  • Creative projects and project pages
  • Project updates and activity
  • Visibility controls

Phase 4 — DiscussionPlanned

  • Forum categories, threads, and replies
  • Editing and moderation foundations
  • Cheers and forum activity integration

Phase 5 — Community recognitionPlanned

  • Ranks, achievements, and flair
  • Community participation history

Phase 6 — EventsPlanned

  • Events and participation
  • Teams, goals, event-specific achievements, and activity

Phase 7 — OperationsPlanned

  • Moderation, reporting, and administrative tools
  • Email, backups, logging, and data export
  • Deployment documentation

Phase 8 — Integrations and sustainabilityLonger term

  • Discord and other useful integrations
  • Optional supporter funding and contribution tracking
  • Store/merchandise integrations and public APIs where justified

What this roadmap is — and isn't

This roadmap communicates the broad sequence of work. Details will change as implementation teaches us what the project needs. Features in future phases are ideas and intentions, not currently available functionality or dated commitments.
