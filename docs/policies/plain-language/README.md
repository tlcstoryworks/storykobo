# Plain-Language Policy Guides

These guides explain storykōbō's formal policies in everyday language. They are intended to help members understand what a policy means in practice, what choices and protections it describes, and what responsibilities apply.

The corresponding formal policy is the governing document if a guide differs. The guides must be updated whenever their formal policies change.
